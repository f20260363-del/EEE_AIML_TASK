Task Description: Analyzing python lists, utilising its functions, and handling data using libraries such as numpy, pandas and matplotlib.

Setup Instructions:
1. Install a text editor such as Visual Studio Code, Jupyter Notebook, or Sublime Text. Even Python IDLE would work well.
2. Install NumPy, Pandas, and Matplotlib libraries using the pip command in command prompt/terminal.
3. Ensure you are not connected to a WiFi network requiring certification during the installation of libraries (especially matplotlib), as the certification blocks the installation process.
4. Ensure you have a csv file editor such as MS Excel or Numbers (for Mac users).
5. For programs including the csv file, it is better to have it in the smae folder as the python file, to prevent unforeseen errors.

Commands to run the solutions:
1. In the text editor, debugging and running the file would run all the 6 programs.
2. Additionally, for the programs including the csv files and plot figures, the files should be named properly in the program, before execution.
